Security Policy

The QR-Based Transport Ticketing and Fee Collection System for Borongan City is designed with security measures to help protect user accounts, driver information, vehicle records, transaction records, and system data.

Account Security

Users are required to use their assigned usernames and passwords to access the system. Users should not share their login credentials with other individuals.

Role-Based Access

Access to system functions is based on the user's assigned role. For example:

  • Administrator — manages system records, users, reports, and system settings.
  • Cashier — manages authorized account loading and related records.
  • Authorized Staff — performs QR verification and records transactions.
  • Driver — accesses permitted driver account information and transaction history.

Data Protection

System data should be protected against unauthorized access, modification, loss, or misuse. Access to sensitive information should be limited to authorized personnel.

Transaction Security

Important actions such as account loading, balance deductions, and transaction recording should be properly validated and recorded in the system.

Audit Records

The system may maintain activity logs to identify important actions performed by authorized users, including account loading, transaction recording, and changes to system records.

Password Security

Users should use strong passwords and should not share their passwords with others. Passwords should be stored securely by the system and should not be displayed to unauthorized users.

Security Incidents

Any suspected unauthorized access, suspicious activity, incorrect transaction, or security concern should be reported to the appropriate system administrator or responsible office personnel.

Note: This security policy is for the proposed academic system and should be reviewed and approved by the appropriate office before actual implementation.
