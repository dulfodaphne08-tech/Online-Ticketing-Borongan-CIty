Vehicle Types and Fee Information

General information about the public utility vehicle types covered by the Borongan City Transport Terminal QR-Based Transport Ticketing and Fee Collection System.

Vehicle Classification Terminal Locations & Routes

This page provides general information about the public utility vehicle types, configured terminal fee schedule, and terminal locations covered by the Borongan City Transport Terminal QR-Based Transport Ticketing and Fee Collection System. It covers vehicle registration information, how vehicle data is used during transactions, the fee schedule, and an interactive GIS map of terminal stations.

01

Covered Vehicle Types

The system can be configured to support the following public utility vehicle types operating under the applicable terminal procedures.

Tricycle

Tricycles are included in the system's vehicle registration and QR-based identification process.

  • Driver information and Driver ID
  • Vehicle type and plate number
  • QR code and account status
  • Prepaid balance
  • Terminal transaction history

Jeepney

Jeepneys are included as one of the vehicle types supported by the system.

  • Driver information and Driver ID
  • Vehicle information and plate number
  • QR code and account status
  • Prepaid balance
  • Terminal transaction history

Multicab

Multicabs are included in the system's vehicle registration and transaction management.

  • Driver ID and driver information
  • Vehicle type and plate number
  • QR code and account status
  • Prepaid balance
  • Terminal transaction records

Bus

Buses are also included in the configurable vehicle types supported by the system.

  • Driver information and Driver ID
  • Vehicle information and plate number
  • QR code and account status
  • Prepaid balance
  • Terminal transaction history
02

How Vehicle Information Is Used

The registered vehicle type is an important part of the system because it may be used when determining the applicable terminal fee.

The general process is:

Driver Registration
Vehicle Registration
QR Code Assignment
QR Scanning
Vehicle Verification
Fee Determination
Balance Deduction
Transaction Recording

This allows the system to connect the driver's registered vehicle with the appropriate terminal transaction.

05

How the Fee Schedule Works

The configured vehicle type may be used by the system to determine the applicable fee during an authorized transaction.

1
Driver Identification

The driver's QR code is scanned by authorized terminal staff.

2
Vehicle Verification

The system retrieves the vehicle type associated with the driver's registered account.

3
Fee Determination

The system identifies the applicable configured fee for that vehicle type.

4
Balance Check

The system checks the driver's available prepaid balance when required.

5
Fee Deduction

If the transaction is authorized and the balance is sufficient, the applicable amount may be deducted.

6
Transaction Recording

The system records the transaction, including the vehicle type, applicable fee, amount deducted, remaining balance, date, time, and other authorized information.

06

Vehicle Information Recorded by the System

During registration, the system may associate the following information with a vehicle:

  • Vehicle type
  • Plate number
  • Driver ID
  • Registered driver
  • Account status
  • Other required vehicle information

This information helps authorized personnel verify that the QR code being presented is associated with the correct registered driver and vehicle.

07

Vehicle Verification at the Terminal

During an authorized terminal transaction, staff may verify:

  • Driver identity
  • Driver ID
  • Vehicle type
  • Plate number
  • Account status
  • Applicable fee
  • Available prepaid balance

If the information does not match the registered record, the transaction may be flagged for verification according to the applicable terminal procedure.

08

Vehicle-Based Transaction Records

Vehicle information is also included in the centralized transaction records.

Authorized reports may be filtered or grouped by:

  • Vehicle type
  • Plate number
  • Driver
  • Date
  • Transaction status
  • Applicable fee

This allows administrators to monitor terminal activity by vehicle type and review historical transactions.

09

Jeepney Report

Multicab Report
  • Number of transactions
  • Recorded fees
  • Driver activity
  • Transaction dates
  • Transaction status
Bus Report
  • Number of transactions
  • Recorded fees
  • Driver activity
  • Transaction dates
  • Transaction status

These reports can help authorized administrators monitor terminal activity and prepare operational summaries.

10

Important Information for Drivers

Drivers should ensure that their registered vehicle information is accurate.

Drivers should report incorrect information such as:

  • Incorrect vehicle type
  • Incorrect plate number
  • Incorrect driver information
  • Incorrect account status

Corrections should be performed through the authorized administrative process.

11

Important System Boundary

System Scope

The vehicle types and fee amounts displayed on this page are part of the system's configured information for the academic project.

Actual vehicle classifications, terminal requirements, fee amounts, operating rules, and schedules are subject to the policies and approved information of the responsible terminal office.

The system does not independently establish or authorize transportation fees.

The system records and applies the configured fee information provided by authorized personnel.
